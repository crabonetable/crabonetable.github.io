개인정보처리방침

시행일: 2026년 11월 26일

양평꽃게한상(이하 '가게')은 홈페이지 방문자의 개인정보를 소중히 다루며, 아래와 같이 처리합니다.

1. 수집하는 항목

네이버 검색광고를 눌러 홈페이지에 들어온 경우에만 아래 정보가 자동으로 기록됩니다. 이름·전화번호 등은 수집하지 않습니다.

  • IP 주소, 방문 시각, 홈페이지에 머문 시간
  • 브라우저 정보, 화면 크기, 언어·시간대 설정
  • 기기 구분용 임의 번호(브라우저 저장소에 저장)
  • 광고 검색 키워드, 광고 추적 값, 들어온 주소와 이전 주소

2. 수집 목적

같은 곳에서 광고를 반복해서 누르는 부정 클릭을 확인하고, 해당 IP에 광고가 보이지 않도록 제한하기 위해서만 사용합니다.

3. 보관 기간

수집일로부터 90일이 지나면 자동으로 삭제합니다.

4. 처리 위탁

  • 수탁자: Cloudflare, Inc. (기록 저장 서버 운영)
  • 위탁 업무: 광고 클릭 기록의 저장·보관

5. 제3자 제공

수집한 정보는 위 목적 외에는 쓰지 않으며, 다른 곳에 제공하지 않습니다. 다만 부정 클릭으로 판단된 IP 주소는 광고 노출 제한을 위해 네이버 검색광고 설정에 등록할 수 있습니다.

6. 방문자의 권리

브라우저의 사이트 데이터를 지우면 기기 구분 번호가 삭제됩니다. 기록 열람·삭제를 원하시면 아래 연락처로 문의해 주세요.
